# Development Guidelines

## General Principles

*   **Clean Code:** Please adhere to clean code principles to maintain a high-quality and readable codebase.
*   **Code in English:** All code, including variable names, comments, and documentation, must be written in English.
*   **Comments:** Only add comments for complex or non-obvious parts of the code. Avoid commenting on self-explanatory code.

## Testing

*   **Test Naming Convention:** Test methods should follow the existing naming convention, for example: `constructor_parsesDateWithFourDigitYear`.
