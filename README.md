# Football API

Este proyecto es una API REST desarrollada en Java con Spring Boot.

## Descripción

La aplicación proporciona endpoints para gestionar información relacionada con el fútbol. Basado en las dependencias, parece incluir funcionalidades para:

*   Exponer endpoints RESTful (Spring Web).
*   Gestionar la persistencia de datos con una base de datos relacional (Spring Data JPA, MySQL, H2).
*   Asegurar la API (Spring Security, JWT).
*   Documentar la API (Swagger/OpenAPI).
*   Y otras funcionalidades.

## Tecnologías Utilizadas

*   **Lenguaje:** Java 21
*   **Framework:** Spring Boot 3.3.5
*   **Persistencia:**
    *   Spring Data JPA
    *   Hibernate
    *   MySQL (producción)
    *   H2 (desarrollo/testing)
*   **Seguridad:**
    *   Spring Security
    *   JSON Web Tokens (JWT)
*   **Documentación:**
    *   Springdoc OpenAPI (Swagger UI)
*   **Build Tool:** Gradle
*   **Testing:**
    *   JUnit 5
    *   Jacoco (cobertura de código)
*   **Otras dependencias:**
    *   Lombok
    *   Caffeine (cache)
    *   Jsoup (para parsing HTML)
    *   Thymeleaf
