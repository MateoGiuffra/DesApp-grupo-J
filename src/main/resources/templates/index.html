Características Técnicas

Conoce las tecnologías y características que hacen posible nuestra API de fútbol

🔐

Autenticación JWT

Sistema de autenticación robusto con JSON Web Tokens almacenados en cookies seguras para proteger todos los endpoints.

  • Tokens seguros en cookies HTTPOnly
  • Expiración automática
  • Refresh tokens
🕷️

Web Scraping

Integración con WhoScored para obtener datos actualizados de jugadores y equipos de manera automatizada.

  • Datos en tiempo real
  • Estadísticas detalladas
  • Información histórica
🗄️

Base de Datos H2

Persistencia eficiente con H2 Database para almacenar usuarios y cachear datos frecuentemente consultados.

  • Rendimiento optimizado
  • Fácil despliegue
  • Datos persistentes
⚡

API REST

API RESTful bien estructurada con endpoints claros para consultas de jugadores y equipos con filtros avanzados.

  • Endpoints intuitivos
  • Filtros por tipo de datos
  • Respuestas JSON estructuradas

Sobre el Proyecto

Desarrollo de Aplicaciones - Universidad Nacional de Quilmes

📚 Contexto Académico

Este proyecto fue desarrollado como parte de la materia Desarrollo de Aplicaciones en la Universidad Nacional de Quilmes. La propuesta combina tecnologías modernas con casos de uso reales del mundo del fútbol.

🎯 Objetivos del Proyecto

  • Implementar un backend robusto con Spring Boot
  • Integrar web scraping para datos en tiempo real
  • Desarrollar un sistema de autenticación seguro
  • Crear una API REST consumible por frontends
  • Aplicar buenas prácticas de desarrollo

🍃 Spring Boot
🗄️ H2 Database
